E-Commerce Sales Analysis Dashboard:

Project Overview:

This project analyzes an e-commerce dataset to understand product sales, customer buying behavior, and overall sales trends. The data is processed using Python and visualized through charts and dashboards to generate meaningful business insights.

Objectives:

Identify top and worst selling products
Analyze customer spending behavior
Track monthly sales trends
Build a visual dashboard for decision-making
Practice end-to-end data analytics workflow

Tools & Technologies:

-> Python (Pandas, NumPy, Matplotlib)
-> Power BI (dashboard visualization)

Dataset Source: Kaggle

Public e-commerce dataset used for educational and portfolio purposes.

Tables included:

-> events.csv – user activity logs
-> orders.csv – order information
-> order_items.csv – items per order
-> products.csv – product details
-> users.csv – customer information
-> reviews.csv – product reviews

Dashboard Highlights:

-> Top 5 best-selling products
-> Worst-performing products
-> Monthly sales trend analysis
-> Customer spending overview
-> Sales performance summary
-> Visual charts for quick insights

Key Insights:

-> Top 5 best-selling products identified
-> Worst performing products highlighted
-> High-value customers discovered
-> Monthly sales patterns analyzed
-> Order value trends evaluated

These insights help support better business decisions in marketing and inventory management.
